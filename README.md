# Makkis Science Room

Makkis Science Room is a modern educational web platform for science learning materials.  
The goal of the project is to make it easy for students to explore, access, and download lesson content in Biology, Chemistry, and Natural Science.

The project is built with Next.js and focuses on a clean, visual, and user-friendly learning experience.

---

## Features

- Home page with introduction and subject navigation
- Dedicated subject pages:
  - Biology
  - Chemistry
  - Natural Science
- Downloadable lesson materials (PDF / PowerPoints)
- Reusable UI components (LessonCard, BackButton, Header, Footer)
- "Coming Soon" pages for future content
- Fully responsive design (mobile + desktop)

---

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Lucide React Icons
