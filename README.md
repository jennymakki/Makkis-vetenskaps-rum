# Teacher's Site

A server-side rendered educational website built with Node.js, Express and EJS.

The site provides structured science learning content for students in a clear and accessible format.

---

## Overview

This project was created to support classroom learning through a digital platform with categorized subjects and lessons. The focus was on simplicity, structure and readability using server-side rendering.

---

## Features

- Server-side rendering with EJS
- Structured navigation for different science subjects
- Responsive design for mobile and desktop
- Clean and readable content layout
- Downloadable learning materials

---

## Tech Stack

- Node.js
- Express
- EJS
- HTML
- CSS
- JavaScript

---

## What I learned

- Server-side rendering with EJS
- Structuring dynamic pages using templates
- Building clean and maintainable page layouts
- Improving responsiveness and user experience
